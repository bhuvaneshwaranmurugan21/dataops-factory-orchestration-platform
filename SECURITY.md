# Security policy

Please report vulnerabilities privately to the repository owner rather than opening a public issue.
Include the affected path, impact, reproducible steps and any suggested mitigation. Do not include
real credentials, callback tokens, customer data or unredacted cloud logs.

The reference code is a portfolio and engineering implementation, not a managed service. AWS
deployment remains the deployer's responsibility, including account controls, network boundaries,
key administration, secret handling, audit retention and incident response.
